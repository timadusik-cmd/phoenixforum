## ⚙️ Архитектура и стек технологий

- **Frontend**: Single Page Application (SPA) с маршрутизацией через History API, компонентной структурой, реактивным состоянием, WYSIWYG/Markdown редактором, загрузкой изображений и звуковыми эффектами.
- **Backend**: Node.js + Express REST API с CORS, защитой от XSS, валидацией входных данных, поддержкой Multer для загрузки файлов.
- **База данных**: SQLite (Better-SQLite3) в режиме WAL с внешними ключами, каскадным удалением и индексами (`server/data/phoenix.db`).
- **Безопасность**:
  - Хеширование паролей через `bcryptjs` (соль 10 раундов).
  - Сессии на базе криптографических JWT-токенов (`jsonwebtoken`).
  - Серверная проверка прав (RBAC): `player` < `helper` < `moderator` < `admin` < `superadmin`.
  - Защита от накрутки опыта и репутации на стороне сервера.
  - Ограничение размера файлов (макс. 5 МБ) и валидация MIME-типов.

## 🗂️ Страницы и маршруты

| Маршрут | Описание |
|---|---|
| `/forum` | Главная страница: Los Santos баннер, хлебные крошки, список категорий со счётчиками и последними сообщениями, правый блок профиля, последние темы. |
| `/forum/category/:slug` | Страница раздела со списком тем, фильтрами («Все», «Закреплённые», «Важные», «Открытые», «Решённые»), пагинацией и кнопкой создания темы. |
| `/forum/thread/:id` | Просмотр темы: авторский сайдбар со статистикой, рангами и репутацией, форматированный текст, цитаты, прикрепления, реакция (👍, ❤️, 🔥, 🏆), модерация (закрепление, закрытие, удаление, решение), форма ответа. |
| `/forum/create` | Создание темы с выбором раздела, тега (Обсуждение, Вопрос, Баг, RP Биография, Жалоба, Торговля), форматированием текста и загрузкой скриншотов. |
| `/forum/search` | Расширенный поиск по ключевым словам, автору, разделу и сортировке (дата, ответы, просмотры). |
| `/forum/members` | Каталог игроков с фильтрацией (Все, Администрация, Игроки), поиском и сортировкой по репутации. |
| `/forum/member/:id` | Профиль игрока с обложкой, сменой аватарки (файл с устройства или прямая ссылка), статистикой тем/сообщений, шкалой опыта (XP) и историей активности. |
| `/forum/notifications` | Центр уведомлений об ответах, реакциях, упоминаниях, предупреждениях и решениях по жалобам с кнопкой «Прочитать все». |
| `/forum/rules` | Свод правил сервера (DM, DB, MG, PG, SK, RK), правила форума и регламент подачи жалоб. |
| `/login` и `/register` | Выделенные страницы авторизации и регистрации (также доступны через быстрые модальные окна). |
| `/account/settings` | Настройки профиля: смена RP имени, биографии, подписи, контактов Discord/Telegram и смена пароля. |
| `/admin` | Панель управления (для модераторов и администраторов): дашборд статистики, рассмотрение жалоб, создание/удаление разделов, управление ролями, блокировка (бан/разбан) с причиной, выдача варнов и журнал аудита (AuditLog). |

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск проекта в режиме разработки
Команда запускает одновременно бэкенд на порту `3001` и Vite dev-сервер с прокси на порту `5173`:
```bash
npm run dev
```

Форум будет доступен по адресу: **http://localhost:5173/forum**

Либо можно запускать сервисы по отдельности:
- Бэкенд API: `npm run server` (порт `3001`)
- Фронтенд клиент: `npm run client` (порт `5173`)

### 3. Сборка для production
```bash
npm run build
```
